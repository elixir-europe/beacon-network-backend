# Contributing

Beacon Network is an open source software and we are welcome any contributions.
Currently the development is managed by the ELIXIR Operations Committee as part of the ELIXIR Infrastructure Services.

## Branches

We have two branches:

master - the release branch which is tagged on every release version (e.g. v0.0.16).
dev - the development branch where all the fixed and new stuff is going,

Once the Operations Committee decides we merge the 'dev' branch into the 'master'.

So all pull requests shuld be done on the 'dev' branch.
